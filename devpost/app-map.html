Application Architecture

IncidentLens transforms messy chat/alert logs into an interactive timeline that highlights false leads and exports audit-ready SRE postmortems.

Interactive Code Tour Stops

1. Input Stream & Gutter Sync — src/components/RawLogEditor.tsx

Manages the log stream editor. Binds vertical scroll events between the textarea and line-number gutter with matched leading-6 height, and renders live highlight banners when a timeline node is clicked.

2. Dual-Engine Extraction — src/services/synthesisService.ts

Contains the structured JSON prompt, OpenAI/Gemini completion caller, and the deterministic offline fallback. It automatically maps rawSnippet text back to line indices so clicking any milestone highlights the exact chat origin.

3. The Kernel Timeline — src/components/TimelineNodeCard.tsx

Renders each milestone card with typed badges: amber dashed sub-threads for False Leads (measuring minutes lost), crimson/violet halos for Root Causes, and emerald markers for Remediation.

Customize Postmortem Template

Update markdownReport in src/data/demoIncident.ts or the prompt schema in src/services/synthesisService.ts.

Adjust Milestone Badges

Edit getBadgeConfig in src/components/TimelineNodeCard.tsx to alter colors, icons, or triage tags.

A Practice to Reuse: Dual-Engine Schema Resilience

When building apps with AI coding agents, don't rely solely on live third-party API availability. By specifying a strict JSON schema and packaging an offline ground-truth dataset (demoIncident.ts), IncidentLens is 100% resilient for demo recordings, automated browser tests, and judge evaluations even when rate limits or network hiccups occur.
